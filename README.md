\# astrbot\_plugin\_Identity-V



第五人格（Identity V）主题的 AstrBot 插件 — 发送第五人格相关的图片和信息。



基于 AstrBot 插件系统开发。



\## 特性



\- 🍑 发送学姐桃图片

\- 更多第五人格相关指令持续更新中...

\## 添加新指令



1\. 在 `src/` 下新建文件夹，如 `src/新指令/`

2\. 创建 `handler.py`，定义 `async def handle(event)`

3\. 在 `main.py` 的 `COMMAND\_DIRS` 中注册映射

4\. 添加 `@filter.command("新指令")` 方法
